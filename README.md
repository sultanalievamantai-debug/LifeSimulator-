# 🧸 VirtualPet

> Симулятор персонажа — корми, укладывай спать, играй и учись. 
> Следи, чтобы здоровье, энергия и настроение не упали до нуля!

## 🎯 О проекте

Мини-игра на чистом JavaScript: у тебя есть персонаж по имени **Stan** 
с тремя характеристиками:

- ❤️ **Здоровье** (0–100)
- ⚡ **Энергия** (0–100)
- 😊 **Настроение** (текст: Отличное / Супер)

Ты можешь выполнять действия, которые меняют статы. 
Задача — держать персонажа в форме!

Проект создан как часть моего портфолио **PortfolioForge** — 
я собираю его постепенно, шаг за шагом.

## 🎮 Как играть

1. Открой `index.html` в браузере
2. Смотри характеристики персонажа в блоке «Мой персонаж»
3. Нажимай кнопки действий:

| Кнопка | Эффект |
|--------|--------|
| 🍔 **Поесть** | ⚡ Энергия +10 (макс. 100) |
| 😴 **Поспать** | ⚡ Энергия +20, ❤️ Здоровье +5 (только если энергия < 80) |
| 🎮 **Играть** | ⚡ Энергия −15, 😊 Настроение = «Супер» |
| 📚 **Учиться** | ⚡ Энергия −20 (только если энергия ≥ 20) |
| 🤒 **Заболеть** | ❤️ Здоровье −20, ⚡ Энергия −15 |
